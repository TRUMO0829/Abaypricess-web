# Нэвтрэлт (`/login`, `/register`)

Заавал биш. Бүртгэлтэй хэрэглэгч нэвтэрвэл хүсэлтийн маягтын **нэр, компани (байгууллага), албан тушаал, утас** автоматаар бөглөгдөнө (засах боломжтой). Бүртгэлгүйгээр хүсэлт илгээсээр байна.

## Урсгал

- **Бүртгүүлэх:** нэр, компанийн нэр, албан тушаал, утас (8 оронтой, `+976`/зай/зураас зөвшөөрнө), нууц үг (4–72 тэмдэгт) ×2 → бүртгэл үүсэж, шууд нэвтэрнэ.
- **Нэвтрэх:** утас + нууц үг. Толгойн баруун талд «Нэвтрэх» / нэрээ дарж «Гарах».
- Нэвтэрсний дараа `?next=` хаяг руу (зөвхөн дотоод зам) буцна. `/contact` дээрх «Нэвтрэх · Бүртгүүлэх» холбоос `/contact` руу буцаана.

## Хадгалалт, аюулгүй байдал

- Supabase `public.accounts` (төсөл `rrnabrxuugxqpicvldus`). Хүснэгт рүү шууд хандах эрхгүй (RLS, policy-гүй) — сайт зөвхөн `register_account` / `login_account` функцийг publishable key-ээр дуудна.
- Нууц үгийг өгөгдлийн сан дотор **bcrypt** (`pgcrypto`)-ээр hash хийнэ. Сайт нууц үгийг хадгалахгүй.
- Нэг бүртгэлд **5 удаа буруу** нууц үг → **15 минут түгжинэ** (функцийг шууд дуудсан ч). Сайт дээр IP тус бүрээс 10 минутад нэвтрэх 10, бүртгүүлэх 5 оролдлогын хязгаар.
- Session: HttpOnly, SameSite=Lax cookie (`adapt_session`, 30 хоног), `AUTH_SECRET`-ээр HMAC-SHA256 гарын үсэгтэй. Хэрэглэгчийн 4 мэдээлэл cookie-д байх тул DB-г дахин уншихгүй.

## Нууц үг сэргээх

SMS/имэйлгүй тул хэрэглэгч өөрөө сэргээх боломжгүй — Adapt-ийн админ Supabase → SQL Editor:

```sql
update public.accounts
set password_hash = extensions.crypt('ШинэНууцҮг123', extensions.gen_salt('bf', 10)),
    failed_attempts = 0, locked_until = null
where phone = '99112233';
```

Түгжээ гаргах: `update public.accounts set failed_attempts = 0, locked_until = null where phone = '…';`

## Env

```
SUPABASE_URL=...                 # үнэлгээнийхтэй ижил
SUPABASE_PUBLISHABLE_KEY=...
AUTH_SECRET=...                  # openssl rand -base64 48 (32+ тэмдэгт). Солиход бүх хэрэглэгч гарна.
```

- `AUTH_SECRET` байхгүй бол production-д «Нэвтрэх үйлчилгээ түр ажиллахгүй» гэж харуулна (dev-д түр нууцаар ажиллана).
- `AUTH_MOCK=1`: e2e — санах ойн бүртгэл, Supabase руу бичихгүй.
